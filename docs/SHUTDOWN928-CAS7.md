# Checkpoint the owned transports and pooled connections

CAS6 propagated client-close exceptions but still trusted HTTPX's early CLOSED flag. Independent transport-level QA proved a second OFF could skip a transport that had failed to close. That witness and CHANGES6 remain unchanged.

The product now retains ClosePlan on each owned HTTP client. It snapshots the default transport, unique non-null mounts and their existing httpcore pooled connections. Each resource advances only after successful aclose. A successfully closed connection is removed by identity under its pool lock before transport shutdown, so the pool neither consumes a failed owner nor repeats successful stream closures. HTTPX state becomes CLOSED only after the plan finishes; an already poisoned CLOSED flag cannot skip this plan.

The product-owned client records the loop used by send, and shutdown routes back to that live loop when needed. GlobalSync uses the plan for its real twin; Library also closes the parent. Injected clients remain caller-owned. No SDK/HTTPX/httpcore source, UI or native formats change.
