# Articulation / Articulación

The library's articulation tools turn one triangulated, unrigged GLB in metres into an editable assembly. The GLB can come directly from image-to-3D. Activate the library explicitly with `vulcan_set_module` (`module: "library"`, `enabled: true`). Tool discovery works with the library stopped. Use the ordinary MCP connection or the Hub's `hub_call_app` for `vulcan`.

## Select and inspect / Seleccionar y comprobar

1. Call `articulation_build` with an absolute `source` path. Pass the predecessor's `source_ref` and `source_sha256` when available. With no `parts`, the tool returns the source bounds and same-camera views for checking the source axes.
2. Name each entry in `parts`. All selection coordinates use the imported scene's XYZ in metres, Z up. The subject's anatomical front can point in any direction. A part takes the intersection of its criteria: `lower` and `upper` bound face centres, `planes` keep centres on their positive side, `colour` compares linear vertex or corner RGB, and `seed` grows from the nearest eligible face along shared edges up to a surface distance. Use `face_ranges` with `source_sha256` to select explicit source faces, using sorted, disjoint inclusive ranges as in the lineage. Planes divide along existing triangle edges. Earlier parts take precedence and remaining faces form `body`. Set `discard: true` for debris.
3. Inspect `source-…`, `source-neutral-…` and `selection-…` from `articulation_view`. Set `cameras`, `focus` and `view_scale` explicitly to replay the framing in another revision. Individual cameras can override the focus and span for joint close-ups. Use the same named cameras in each pose's optional `cameras` list. The receipt retains the world matrices and spans. The editable scene includes the original in a reference collection, hidden at first.
4. The tool caps simple closed cut loops on both sides and reports remaining open and non-manifold edges per part, including new open cut edges. Pre-existing open edges are normally retained. Set `repair_original: true` to attempt a closure that includes them. Color and UV attributes on original triangles are retained. Caps on UV-textured sources have no source UVs. Review them in the editable scene. A fused or missing surface may need local reconstruction. Use `panels` for added planar parts with an explicit ordered outline, thickness, and reference, such as a map with a clipped corner.
5. For interrupted or branched separation contours, supply `seam_repairs` as pairs of retained source parts, for example `[["sleeve", "body"]]`. Each patch follows the specified cut and routes interruptions over nearby original edges. The receipt verifies two uses of every targeted cut edge and reports how many routing edges were open, regular or already non-manifold. A route crossing a regular edge adds a third face there. Inspect the patch and its silhouette from both sides before passing the piece on.

## Rig and pass on / Articular y traspasar

- Set a part's `pivot` to change its origin without moving its rest surface. Define the armature with `bones` (head, tail, optional parent) and connect parts via `bone` and `body_bone`. Each bound part uses weight 1 on that bone. The editable file lets a worker adjust the rig and weights.
- `poses` define bone-local Euler XYZ rotations in degrees, an optional turn around world Z and a list of objects hidden from the pose preview and frozen export. The editable scene and skinned GLB store the rotations on a timeline, starting at the rest pose and spaced by 24 frames. Visibility choices are in the recipe and frozen outputs.
- The receipt gives the byte size and SHA-256 of each export. It identifies the editable `.blend`, skinned `rigged.glb`, each unskinned `pose-*.glb`, the replayable `recipe.json` and `lineage.json`. Use a frozen pose for the print job. The cutter reports surface topology. Conversion to a printable solid belongs to the print preparation step.
- `lineage.json` records inclusive runs of zero-based source face indices in the order it imported the exact GLB. Each retained piece keeps those faces in order, with reconstructed cap triangles appended and explicitly identified. A named seam records its output face range and the source vertex pairs along both the cut and its routing edges. Discards have their own source ranges. Added panels record their references. A defect report can cite the source SHA, the piece, the pose and the camera.
- `articulation_get` reopens a package by ID. Each build publishes a separate directory only once its exports are complete. `articulation_undo` withdraws the directory and returns the arguments for restoring it. Keep the recipe to repeat or revise an operation.

## Viewer contact and handoff

In the library, open a GLB and use **Mark contact / Marcar contacto**. For an animated file, seek to the contact in the clip first. Click the visible surface and download the JSON with the point, click ray, camera, animation time and PNG crop. **Load camera / Cargar cámara** restores its framing. Coordinates in the receipt are Z-up in metres. The displayed triangle index identifies a triangle in the loaded primitive. To select a canonical face, use the original unrigged source in the viewer and send its mark's `source_sha256`, `origin`, `direction` and `point` together with the absolute path as `source` to `articulation_pick`. Its returned `face_ranges` can go directly in a recipe for the same SHA-256.

In **Animations / Animaciones**, open the rig and run **Inspect animations / Inspeccionar animaciones**. The inspection and its manual instructions follow an English or Spanish browser locale. Clip and bone names come from the rig. The agent report keeps the existing English `manual` list and includes the matching Spanish list in `manual_es`.

Use `reconstructions` for separately authored pieces. Each entry requires a triangulated GLB, SHA-256, a lineage reference and a source-space `anchor`. Bind it to an existing bone with `bone`. To replace part of the inferred mesh, mark that region as a discarded source selection. The rebuilt mesh and the discarded faces have separate lineage entries in the receipt. A panel can carry a `source_object` object with the dossier `ref`, its SHA-256 `revision`, `dimensions_m` and `finish`. The outline and panel pivot travel with it as the geometry and grip.

To build a rectangular panel with a clipped corner from a dossier, set `panels[].dossier_object` and `panels[].pivot`. Supply the absolute JSON `path`, its SHA-256 `revision` and the object's `ref` from the dossier's `objects` array. The tool reads `Tamaño` or `Size` (one width × height in mm, cm or m), `Defecto` or `Defect` (for example, “Lower right corner torn diagonally”), and `Material`. Include `right` and `up` as perpendicular source-space directions, a uniform `scale` (1 at full size), and `grip_uv` measured from the full rectangle's lower left, such as `[0, 0.5]` for the middle of the left edge. The tool places that point at `pivot` and cuts the specified corner by 15% of the shorter side along each adjoining edge. Supply just this geometry source for the panel. The receipt records the dossier dimensions, scaled panel dimensions, corner, cut length, outline, grip and finish. The finish travels as a reference. The existing `outline` and optional `source_object` remain available for manually drawn panels.

Set `game_triangle_budget` for an additional skinned game GLB. Its receipt counts the triangles per named piece in the exported file and gives the joints' rest pivots, axes and parents in glTF coordinates. The game copy keeps the animation tracks and named meshes. `game.pose_seconds` gives the markers' times in that clip. For print, send a frozen pose and its exact SHA-256, including the assembled base where required.

When the library tool schema changes, refresh the snapshot with `python scripts/refresh_studio_catalog.py` in the app environment and run the cold stdio test.

En castellano, el flujo es seleccionar las caras, revisar las vistas de frente y espalda, reparar los bordes del corte, ligar las piezas a huesos y pasar la pose congelada a impresión. La selección trabaja en metros. Las medidas del paquete indican las aristas abiertas o con más de dos caras que requieren revisión.

Para afinar una selección por identificador de cara, combina `face_ranges` con `source_sha256`. Para reparar un encastre abierto o ramificado, indica las dos piezas conservadas en `seam_repairs`, por ejemplo `[["manga", "body"]]`. El parche recorre el corte y enlaza sus tramos por aristas cercanas. El linaje conserva las caras originales y registra el tramo añadido y las aristas que lo unen a cada pieza. El recibo indica cuántas aristas del corte se cerraron y cuántas aristas de enlace tenían una, dos o más caras antes del parche. En las poses de reposo y movimiento usa las mismas cámaras, con `focus` y `view_scale` por cámara para encuadrar el encastre.

Para un panel rectangular con una esquina cortada, pasa en `dossier_object` la ruta absoluta al JSON del expediente, su SHA-256 y la referencia del objeto. El puesto lee la anchura y altura de `Tamaño` (un único par en mm, cm o m), la esquina de `Defecto` (por ejemplo, «Le falta la esquina inferior derecha, rasgada en diagonal») y el acabado de `Material`. Coloca el panel con los ejes perpendiculares `right` y `up`, la escala uniforme `scale` y el agarre `grip_uv`, contado desde abajo a la izquierda del rectángulo completo. Así, `[0, 0.5]` sitúa el centro del borde izquierdo en `pivot`. El corte abarca el 15 % del lado menor en cada borde adyacente. El recibo conserva la escala, las medidas originales y aplicadas, el contorno, la esquina, el agarre y el acabado como referencia. Los paneles manuales se siguen construyendo con `outline`.
